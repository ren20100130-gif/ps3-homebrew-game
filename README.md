# チンチンニガニガpoop forゲイ — PS3 Homebrew

PS3 CFW向けミニゲームの開発リポジトリです。

## 現在の状態

これは**開発スターター**です。現時点ではPS3で起動できる完成品やPKGではありません。

- 共通ゲームロジック: 初期実装あり
- PS3コントローラー入力・画面描画: 未実装
- PS3音声再生と音声素材: 未実装
- PARAM.SFO / ICON0.PNG / PKG: 未作成
- 実機テスト: 未実施

## 操作予定

| DualShock 3 | 表示・読み上げ |
|---|---|
| ○ | チンチン |
| × | ニガニガ |
| □ | poop |
| △ | ゲイ |
| START | リセット |

音声は、以前のブラウザ試作で使った「普通の読み上げ」方向を想定しています。

## ソース構成

- `src/game_logic.h`, `src/game_logic.c`: プラットフォーム非依存のゲーム状態
- `src/ps3_main_template.c`: PS3側接続用の未完成テンプレート
- `docs/BUILD_NOTES_JA.md`: ビルド環境の注意

## 次の作業

1. 使用するPSL1GHT/ps3dev環境とサンプルを固定
2. PS3の映像・コントローラー処理を実装
3. 音声ファイルと再生処理を追加
4. アイコン・PARAM.SFO等を用意してPKG化
5. CFW実機で動作確認

**注意:** このリポジトリにファイルを置いただけではPKGは生成されません。ビルド環境と対応したMakefileが必要です。
