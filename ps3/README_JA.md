# PS3 実機ランタイム（開発中）

PSL1GHT のサンプル構成を参考にした実機用エントリーポイントです。

## ビルド
PSL1GHT の toolchain 環境を用意し、リポジトリ直下で次を実行します。

```sh
cd ps3
make
```

## 現在の実装
- PS3 video / RSX 初期化とフレームループ
- DualShock 3 の ○×□△ / START 入力
- ボタン入力をゲームロジックへ反映
- 入力ごとに背景色を変更してイベントを可視化
