# PS3 実機ランタイム（開発中）

PSL1GHT の公開サンプル構成を参考にした、CFW向けアプリの初期ランタイムです。

## ビルド環境

PSL1GHT / ps3dev のツールチェーンが必要です。

```sh
export PSL1GHT=/path/to/PSL1GHT
cd ps3
make
```

PKG化を試す場合:

```sh
make pkg
```

## 実装済みの土台

- RSX 初期化とフレームループ
- DualShock 3 の ○×□△ / START 入力取得
- 共通ゲームロジックとの接続
- ソフトウェア描画による英数字UI（5x7ビットマップフォント）
- 入力に応じた画面色と反応テキストの切り替え
- START によるゲーム状態リセット

## 未完了

- 通常の読み上げ音声素材とPS3音声再生処理

## 注意

このリポジトリには、現時点で完成版PKGはありません。Makefile は PSL1GHT の標準ルールを使う構成ですが、実際のビルドはまだ検証できていません。
