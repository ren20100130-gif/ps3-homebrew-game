# PS3 実機ランタイム（開発中）

PSL1GHT の公開サンプル構成を参考にした、CFW向けアプリの初期ランタイムです。

## ビルド環境

PSL1GHT / ps3dev のツールチェーンが必要です。

```sh
export PSL1GHT=/path/to/PSL1GHT
cd ps3
make
```

PKG化を試す場合:

```sh
make pkg
```

## 実装済みの土台

- RSX 初期化とフレームループ
- DualShock 3 の ○×□△ / START 入力取得
- 共通ゲームロジックとの接続
- ボタンごとの背景色フィードバック
- START によるゲーム状態リセット
